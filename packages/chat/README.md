# determly/chat

Persona SSE wire for Determly. No Laravel dependency.

Other chats and `determly/chat-laravel` use `Determly\Chat\Wire\Session`. Recipes register tools on `Determly\Chat\ToolRegistry`.

This package lives in the [determly-ai-chat](https://github.com/coresmart/determly-ai-chat) monorepo. See the repository README for install.
